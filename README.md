O objetivo desse projeto é recriar a tabela de [Resumo diário de serviço antivetorial](src\imgs\image.png) como meio de facilitar e otimizar o trabalho dos ACEs durante o serviço.

Este projeto, trata-se do passo inicial para este objetivo, explorando a recriação dessa mesma tabela com diferentes tipos de bancos de dados. 

Trata-se de um projeto pessoal simples para fins de aprendizado.
Entender como diferentes bancos de dados podem ser utilizados para uma mesma situação e compreender as vantagens e desvantagens de cada um deles com experiência prática.
